# Локальное распознавание Faster Whisper

В русскую сборку NexQ добавлен Faster Whisper через скрытый локальный Python-процесс. Микрофон и системный звук используют существующие устройства записи, события расшифровки и окно встречи. Один процесс и одна загруженная модель обслуживают оба источника последовательно. API-ключ распознаванию не нужен. Провайдер ответов ИИ настраивается отдельно.

## Модель и настройки

Основная модель: [`voxta/faster-whisper-large-v3-turbo-int8`](https://huggingface.co/voxta/faster-whisper-large-v3-turbo-int8), ревизия `0af70a48d94da73866dd6e320c8830f8e57b9e11`. Пять обязательных файлов занимают 817 835 585 байт. SHA256 model.bin: `7482f978f9493b93b3d0bf68a148a1a62ca02547e8ee981358ff8ef2de8a9418`.

Постоянная папка: `%APPDATA%\com.nexq.app\models\faster_whisper\voxta-large-v3-turbo-int8`. При запуске через упакованное приложение Windows может использовать `LocalCache\Roaming` своего пакета. Модель установлена в оба существующих каталога этой машины. `MODEL-MANIFEST.json` хранит версию, размеры и контрольные суммы. Проверка и повторный запуск используют уже скачанные файлы. Само распознавание не скачивает модели.

Откройте «Настройки → Распознавание речи → Faster Whisper». Там доступны язык (автоматически / русский / английский), устройство (автоматически / NVIDIA CUDA / CPU), формат вычислений, качество, Silero VAD и термины. При автоматическом выборе используется совместимая видеокарта, иначе CPU INT8. Качество задаёт beam size: «Быстро» — 1, «Сбалансированно» — 3, «Точнее» — 5. Поле терминов необязательно; добавляйте только вероятные слова: лишние подсказки могут ухудшать результат.

`large-v3-turbo` и `large-v3` доступны в существующем менеджере локальных моделей. Их скачивание и выбор выполняются явно; автоматически они не заменяют основную INT8-модель. Они требуют больше памяти.

## Запуск и работа

Запускайте NexQ обычным ярлыком на рабочем столе. Терминал, отдельный сервер и ручной запуск Python не нужны. Среда находится рядом с nexq.exe в `runtime\faster-whisper`. Установка не меняет системный Python.

Начните встречу обычной кнопкой или Ctrl+M. В индикаторах обоих источников должен отображаться Faster Whisper / Turbo INT8. Звук поступает в прежний канал захвата Windows, преобразуется в моно PCM16 16 кГц и передаётся скрытому процессу через стандартные потоки, без открытого сетевого порта. Инициализация и распознавание выполняются вне потока интерфейса.

После паузы около 700 мс формируется окончательная строка. Максимальный фрагмент — 20 секунд. На GPU первый промежуточный проход запускается после 2 секунд накопленного звука, последующие — примерно через каждые 4 секунды. Предварительный проход использует быстрый поиск (beam size 1) без временных токенов. Окончательный проход сохраняет выбранное качество. Строки имеют отдельный признак и заменяются окончательным текстом под тем же идентификатором. На CPU такие повторные проходы отключены для снижения нагрузки. Клик по фразе и отправка последнего вопроса пробелом сохраняются.

При включённом Silero VAD фрагменты, в которых фильтр не обнаружил речь, отбрасываются до определения языка и запуска Whisper. Для речевых фрагментов используются те же параметры VAD, а временные отметки восстанавливаются по исходному звуку. Это уменьшает занятость общей очереди фоновым шумом.

Очередь каждого источника хранит до трёх ожидающих окончательных фрагментов и только самый свежий промежуточный вариант. Пока обработчик занят другим источником, новый промежуточный вариант заменяет старый. Поступление окончательного фрагмента отменяет ожидание устаревшего промежуточного прохода. Окончательный звук сохраняется в порядке поступления; при заполнении его очереди действует обратное давление, без отбрасывания звука внутри STT-провайдера. Два источника получают доступ к общей модели через существующий Tokio Semaphore с одним разрешением, в порядке запросов. Уже запущенное распознавание не прерывается. Исходное время захвата аудио сохраняется даже при задержке его передачи провайдеру.

Если Windows перестаёт присылать пакеты после окончания воспроизведения, проверка каждые 100 мс завершает накопленную фразу после 700 мс без пакетов. При остановке сессии обработка оставшегося звука ограничена по времени; при слишком медленной обработке показывается ошибка вместо бесконечного ожидания. При закрытии всего приложения родительский контроль завершает Python-процесс. При сбое CUDA движок пробует CPU INT8. Диагностика содержит устройство, формат, длительность загрузки/распознавания, ожидание очереди, передачу результата и тип ошибки, без текста речи и подсказок. Ограничение очереди не ускоряет саму модель: если обработка окончательной речи длительно медленнее её поступления, потребуется отдельно выбрать компромисс качества и скорости.

## Сборка и повторная проверка

Для подготовки среды разработчику нужны Windows x64 и `uv` в PATH:

```powershell
./scripts/setup-faster-whisper.ps1
# Для компьютера без NVIDIA:
./scripts/setup-faster-whisper.ps1 -SkipGpuLibraries
# Если модель уже установлена:
./scripts/setup-faster-whisper.ps1 -SkipModel
npm run tauri build
```

Скрипт ставит переносимый Python 3.12.14 и зависимости в изолированный `runtime/faster-whisper/packages`, использует lock-файлы с хешами и сохраняет модель в постоянном каталоге. Сборка подготавливает worker автоматически и включает среду в ресурсы установщика. Готовому приложению uv и инструменты сборки не нужны. CPU не требует CUDA; для ускорения нужен совместимый драйвер NVIDIA. В текущую сборку включены проверенные cuBLAS 12.4, cuDNN 9.1 и CUDA Runtime 12.4.

Проверки интерфейса: `npm test`, `npx tsc --noEmit`. Проверки Python без загрузки модели:

```powershell
./runtime/faster-whisper/python/python.exe -I python/faster_whisper/test_worker.py
```

Для настоящих аудиотестов используйте собственные тестовые или публичные WAV-файлы:

```powershell
./runtime/faster-whisper/python/python.exe -I python/faster_whisper/smoke.py --model "ПУТЬ_К_МОДЕЛИ" --russian "ru.wav" --english "en.wav" --mixed "mixed.wav" --report "smoke-result.json"
```

Этот тест запрещает сетевые соединения во время распознавания, проверяет русский, английский, смешанную речь, повторное использование модели и принудительный CPU INT8. Отчёт намеренно содержит текст только переданных тестовых записей.

Настоящий тест внутреннего провайдера Rust требует WAV моно PCM16 16 кГц, переменных `NEXQ_FW_MODEL`, `NEXQ_FW_WAV`, `NEXQ_FW_DEVICE=cpu` или `cuda`:

```powershell
cd src-tauri
cargo test --release --locked --lib stt::faster_whisper::tests -- --include-ignored --nocapture
```

Для воспроизведения синтетической беседы в реальном темпе предусмотрен отдельный игнорируемый тест `tests/faster_whisper_latency.rs`. Переменные `NEXQ_FW_MODEL`, `NEXQ_FW_FIXTURES` и `NEXQ_FW_REPORT` задают локальную модель, папку с тестовыми WAV и отчёт. Он проверяет русский и смешанный образцы, тишину, продолжительную речь и два одновременных источника, не открывая микрофон и не создавая встречу. Запуск: `cargo test --release --locked --test faster_whisper_latency -- --ignored --nocapture`. WAV должны быть синтетическими; итоговый отчёт содержит их распознанный текст для сравнения точности.

## Измеренные результаты и ограничения

На NVIDIA RTX 3050 Laptop 4 ГБ с драйвером 566.07 использован CUDA INT8+FP16. В проверке 30.10.2026: русская запись 8,3 с — 2,06 с обработки, человеческая английская запись 3,85 с — 0,98 с, смешанная запись 5,51 с — 0,98 с. При повторном запросе счётчик загрузок оставался равен 1. На CPU INT8 те же 8,3 с русского звука обрабатывались 19,20 с. Это измерения коротких тестовых записей, без времени захвата и ожидания паузы; они не гарантируют такую скорость на любой речи или при двух одновременно говорящих источниках.

Русский и смешанный образцы синтезированы, английский — публичный человеческий голос (JFK). Смешанный образец без подсказок распознан как «Что такое Large Object Heap? И зачем он нужен?». Проверены тишина, отсутствие модели, неподдерживаемый формат вычислений и CPU без доступной CUDA. Шум, одновременная речь, тихий/перегруженный микрофон и редкие термины по-прежнему могут приводить к ошибкам. После установки интернет для STT не нужен; для получения ответов выбранной облачной модели он требуется отдельно.

Лицензии движка, исходной Whisper-модели и зависимостей находятся в `python/faster_whisper/licenses`, `THIRD-PARTY-NOTICES.md` и установленной среде рядом с приложением.
