# Приватность при демонстрации экрана

Включение: **Настройки → Общие → Режим приватности при демонстрации**. Состояние сохраняется. Окна остаются видны владельцу компьютера и исключаются из поддерживаемого захвата Windows. Прозрачность окна — отдельная настройка.

Все постоянные окна запускаются скрытыми, защита восстанавливается до первого показа. Новые окна получают нативный обработчик при создании. Диагностика и уведомление об обнаруженном созвоне создаются скрытыми и подготавливаются перед показом. При ошибке установки защиты показ блокируется. При скрытии защита снимается до скрытия поверхности; перед повторным показом возвращается. Это сохраняет исправление зависания рабочего стола.

В этом режиме скрываются значки NexQ в трее и на панели задач. Вернуть приложение можно **Ctrl+Shift+B** (если сочетание не переназначено). **Ctrl+Shift+H** переключает защиту. Приложение не изменяет значки рабочего стола, список процессов и интерфейс других программ.

## Управление из другого приложения

| Сочетание по умолчанию | Действие |
| --- | --- |
| Ctrl+Shift+Q | Ответить на последний блок расшифровки в текущей сессии |
| Ctrl+Shift+A | Снимок монитора с окном сессии → запрос модели |
| Ctrl+E | Независимая оценка своего ответа или выбранных ответов |
| Ctrl+Shift+B | Скрыть / вернуть NexQ, сохранив запись |
| Ctrl+M | Завершить сессию и скрыть оба главных окна |

Три новых фоновых сочетания переназначаются в настройках горячих клавиш. Занятые сочетания приложения отклоняются. Если Windows не разрешает регистрацию, сообщение об этом появляется внутри NexQ. Удержание клавиш не создаёт очередь запросов. Ctrl+A сохраняет выделение текста в других программах и в полях ввода; внутри сессии вне поля ввода запускает снимок, как раньше.

Снимок отправляется только по действию пользователя. Защищённые окна не скрываются и не мигают во время захвата. Если исключение не подтверждено, применяется прежнее временное скрытие. Восстановление не переводит фокус с другого приложения и не открывает завершённую сессию. Изображение не записывается в историю, журнал или буфер обмена. Оценка ответа остаётся в отдельном канале запросов; тема и контекст текущей сессии сохраняются.

## Системные диалоги

Окна выбора файла и папки принадлежат Windows и не являются защищёнными окнами Tauri. В режиме приватности NexQ блокирует их открытие и показывает пояснение внутри приложения. Для загрузки доступно перетаскивание. Для экспорта и выбора папки временно выключите режим. Включение режима при уже открытом системном диалоге также блокируется. Подтверждение замены задач отображается внутри NexQ; стандартное контекстное меню WebView отключается в этом режиме, собственные меню приложения продолжают работать. Приложение не отправляет системные уведомления с содержимым сессии.

## Ограничения и проверка перед созвоном

Механизм Windows `WDA_EXCLUDEFROMCAPTURE` поддерживается начиная с Windows 10 версии 2004. Он работает с определёнными способами захвата при работающем композиторе рабочего стола и не даёт универсальной гарантии. В старых версиях Windows вместо исключения возможно пустое/чёрное окно. [Документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

Tauri предоставляет защиту содержимого окна; здесь используется существующий Win32-механизм с обработкой показа и скрытия, чтобы сохранить исправление зависания прозрачного WebView. [Документация Tauri](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindowBuilder.html#method.content_protected).

Перед реальной демонстрацией проверьте результат на стороне зрителя в нужной программе, отдельно для показа всего монитора и выбранного окна. Код и локальные проверки не подтверждают совместимость с Zoom, Teams, Meet, OBS или удалённым рабочим столом без фактической проверки каждого режима. Камера, направленная на физический экран, видит локальное изображение.
